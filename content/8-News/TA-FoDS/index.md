The Foundations of Data Science (FoDS) course, offered by **Dr. Babak Khalaj** and **Dr. Saberi**, provides a modern overview of data science, covering:

- Data and statistics
- Classical and modern machine learning
- Deep learning and transformers
- Generative models
- Real-world ML systems, deployment, and monitoring

The course aims to connect **foundations → modern ML → real-world ML systems**.
